# ABM Respiratory Care

> ABM Respiratory Care (ABMRC, LLC) is a privately held respiratory medical device manufacturer that
> designs, builds and sells airway clearance and lung ventilation hardware under the BiWaze brand for
> both hospital and home-care settings. It is a physical device company, not a software or API
> provider: there is no developer portal, no public API, no SDK and no machine-readable specification
> anywhere on its public web surface.

## Company

- Legal / operating entities: ABMRC, LLC (Eagan, Minnesota, USA); Advanced Biomechanics Private

- Markets: hospital respiratory care, home care, durable medical equipment / reimbursement channels
- Website: https://abmrc.com/

## Products (hardware, not APIs)

- [BiWaze Clear — hospital](https://abmrc.com/biwaze-clear-hospital/): oscillation and lung expansion
  (OLE) therapy system for hospital use.
- [BiWaze Clear — home care](https://abmrc.com/biwaze-clear-home-care-2/): OLE therapy in the home,
  with an HCPCS code for home OLE therapy.
- [BiWaze Cough — hospital](https://abmrc.com/biwaze-cough-hospital/): mechanical
  insufflation-exsufflation (cough assist) for hospital use.
- [BiWaze Cough — home](https://abmrc.com/biwaze-cough-home/): cough assist therapy in the home.
- [Products overview](https://abmrc.com/products/)

## API surface

None published. Verified 2026-09-06:

- No developer, api, docs, portal, status, app or data subdomain resolves on abmrc.com (all NXDOMAIN).
- /openapi.json, /openapi.yaml, /swagger.json, /api-docs and /apis.json return the WordPress 404 page
  on abmrc.com; /openapi.json returns 404 on eifu.abmrc.com.
- /llms.txt returns 404 on both abmrc.com and eifu.abmrc.com.
- Every named /.well-known/ path (security.txt, openid-configuration, oauth-authorization-server,
  api-catalog, ai-plugin.json, agent-card.json, agent.json) returns 404 on abmrc.com and
  eifu.abmrc.com, and 301 on www.abmrc.com and the legacy abmrespiratorycare.com domain.
- The only machine-readable endpoint on either host is the default WordPress core REST API at
  /wp-json/ (plus The Events Calendar plugin namespace tribe/events/v1), which is CMS scaffolding
  shipped by WordPress rather than a product API ABM Respiratory Care designed, documents or supports.
- The BiWaze devices are standalone therapy hardware; the public product pages document no
  connectivity, telehealth data service, EMR/EHR integration or partner interface.
